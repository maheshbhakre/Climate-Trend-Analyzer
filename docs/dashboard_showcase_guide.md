# Dashboard Showcase Guide

## Capture set

Capture the following views at a desktop viewport after the app has loaded:

- `dashboard_overview.png` — Executive Overview with KPI cards and annual signal.
- `global_trends.png` — Global Climate Trends / Trend signal tab.

Use a consistent viewport, hide browser chrome, and include the left navigation so the product scope is immediately legible. Keep the visible chart tooltip off the final capture unless it adds useful context.

## Visual QA checklist

- No horizontal scrolling at desktop, laptop, tablet, or mobile widths.
- KPI values and status labels remain readable at 100% zoom.
- Plotly legends and hover labels use the shared dark theme.
- No chart uses default white backgrounds or default Plotly colors.
- Critical alerts remain legible without depending on red/green perception alone.
- Source limitations remain available on Platform Information and Dataset Explorer.
